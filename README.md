# 🍽️ FoodFusion

### Recipe Sharing Website | Academic Project

## 📖 About the Project

FoodFusion is a recipe-sharing website I developed as an individual academic project during my NCC Level 5 Diploma in Computing at Strategy First College.

The website allows users to explore recipes, share their own cooking ideas, and interact with other users through comments and ratings.

Through this project, I gained practical experience in full-stack web development, database management, and implementing interactive website features.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive features
- **PHP** – Backend development
- **MySQL** – Database management
- **Bootstrap** – Responsive design

## ✨ Key Features

- User registration and login
- Browse and search recipes
- Share recipes with ingredients and instructions
- Recipe categories and dietary preferences
- Comment on and rate recipes
- Save favorite recipes
- User profile management
- Contact form and newsletter subscription

## 🚀 How to Run

1. Install a local PHP and MySQL environment, such as XAMPP or MAMP.
2. Place the project folder inside the local web server's document directory.
3. Create a MySQL database named `FoodFusion`.
4. Import `FoodFusion_schema.sql` into the database.
5. Configure the `DB_HOST`, `DB_NAME`, `DB_USER`, and `DB_PASSWORD` environment variables.
6. Start the web server and MySQL.
7. Open the project through your local server.

**Note:** The included SQL file contains the database structure only. Sample recipes and user accounts are not included.
